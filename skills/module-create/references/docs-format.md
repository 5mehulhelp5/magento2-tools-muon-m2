# Documentation Format Rules

This skill does not define its own `README.md` or `CHANGELOG.md` format — both are delegated in full
to `docs` (Step 6), which owns the single canonical template for each: the README
section structure lives in `docs/templates/readme.md` and
`docs/references/doc-structure.md`; the CHANGELOG structure and category vocabulary
follow the canonical `context/references/changelog-format.md`. See
`references/documentation-guide.md` for how and when the delegation runs.
